# xatframe

Página minimalista para usar como xatframe no xatspace.

## Editar

- **Nome, frase e informações:** `index.html`
- **Fotos:** troque os arquivos em `img/` mantendo os nomes (`perfil.jpg`, `foto-1.jpg`, `foto-2.jpg`).
  - Para adicionar mais fotos ao slide, duplique uma linha `slider__img` e uma `backdrop__img` no `index.html`.
- **Tempo do slide:** `data-interval="5000"` no `index.html` (em milissegundos).
- **Cores:** variáveis no topo do `style.css`.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub (ex.: `xatframe`).
2. Envie todos os arquivos desta pasta (`index.html`, `style.css`, `script.js`, `img/`).
3. No repositório: **Settings → Pages → Branch: `main` / `(root)` → Save**.
4. Depois de 1–2 minutos o link fica disponível:
   `https://SEU-USUARIO.github.io/xatframe/`
5. Cole esse link nas configurações de aparência do seu xatspace (power ME).
